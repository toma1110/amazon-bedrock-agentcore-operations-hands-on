# 第10章 おわりに｜後片付けと実務への応用

## この章で学ぶこと

HarnessやGatewayなどのAgentCoreリソース、ナレッジベース、S3の教材データ、作成したアラーム、ロググループ、IAMロールの中から、演習で作ったものを特定します。依存関係を確かめて片付け、各サービスの画面で削除後の状態を確認します。

## このページで案内する講義

- `s10-l01`　演習で作ったリソースを削除し、残っていないことを確かめる
- `s10-l02`　講座を振り返り、実務で最初に試すことを選ぶ
- `bonus-next-steps`　ボーナスレクチャー

## 完了時

演習用リソースが残っていないことを確かめ、実務で試すことを一つ選びます。
