# 第5章 AgentCore Memoryで記憶と保持を管理する

## この章で学ぶこと

会話状態、短期イベント、長期記録の役割を比べ、次の会話に残す情報を選びます。利用者ごとの分離、保持期間、指定した記録の削除を扱います。

## 講義とハンズオン

- `s05-l03`　利用者ごとに好みを保存し、新しい会話で取り出す
- `s05-l05`　指定したMemoryの記録を確認して削除する
