# 第5章 AgentCore Memoryで記憶を管理する

## この章で学ぶこと

短期イベントと長期記録の役割を比べ、次の会話に残す情報を選びます。同じ利用者IDで新しいセッションを始めた場合と、別の利用者IDで始めた場合に取り出せる記録を比べます。保持期間と、対象の記録を削除した後の状態も確認します。

## このページで案内する講義

- `s05-l03`　会話を変えた場合と利用者を変えた場合の記憶を比べる
- `s05-l05`　対象のMemoryイベントや長期記録を特定して削除する
