# 第4章 Gateway・Identity・Policyでツールへのアクセスを管理する

## この章で学ぶこと

既存APIをMCPツールとして公開し、呼び出し元の認証、接続先で使う権限、Policyによる許可・拒否を分けて確認します。Identityの認証経路もたどります。

## 講義とハンズオン

- `s04-l03`　既存のログ取得APIをMCPツールとして公開する
- `s04-l04`　MCPクライアントとHarnessでツールを確かめる
- `s04-l06`　Cedar Policyで同じツールへのアクセスを制御する
