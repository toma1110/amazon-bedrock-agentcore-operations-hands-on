# 第9章 おわりに｜後片付けと実務への応用

## この章で学ぶこと

演習で使ったHarness、Gateway、Policy、Memory、ログ、IAMロールなどの演習用リソースを所有範囲と依存関係から照合し、削除後に残存を確かめます。サンプルアプリは前章で片付けます。Knowledge Baseの補足と、実務で次に試すことも扱います。

## 講義とハンズオン

- `s09-l01`　演習用リソースを削除し、残っているものを確認する
- `s09-l02`　【補足】Knowledge Baseで社内資料を検索し、回答に活用する
- `s09-l03`　実務へ持ち帰ることと、次に学ぶことを決める
- `bonus-next-steps`　ボーナスレクチャー

## 完了時
