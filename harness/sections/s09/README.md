# 第9章 総合演習｜AgentCoreの機能を組み合わせて5xxを調査する

## この章で学ぶこと

サンプルアプリを操作し、HTTPステータスとリクエストIDを控えます。ブラウザーでCloudWatch Logs Insightsを開き、対象の時間帯とリクエストIDからアプリが出力したログを調べます。第8章で選んだ版のエージェントにも同じログを読ませ、発生した事象はログ、次の調査は第7章の手順書を根拠に報告します。ログのダウンロードは不要です。

エージェントは、許可した範囲でログと手順書を読み取ります。本文に操作手順が書かれている場合は、その出典を示し、次の調査として受講者に提案します。

## このページで案内する講義

- `s09-l02`　CloudWatchのログとエージェントの回答を照合する
- `s09-l05`　調査の流れを振り返り、サンプルアプリを片付ける
