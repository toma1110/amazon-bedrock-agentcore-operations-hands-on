# 第8章 評価で更新を判断し、版を切り替える

## この章で学ぶこと

基準版と、設定を一つ変えた候補版を同じ評価条件で比べます。評価結果、応答時間、利用量を基に採用する版を決め、名前付きエンドポイントが指す版を切り替えます。実行上限の効果は比較用のエンドポイントから呼び出して確かめます。

## このページで案内する講義

- `s08-l02`　同じ評価ケースでHarnessの2つの版を比べる
- `s08-l03`　名前付きエンドポイントが指す版を切り替え、元に戻す
- `s08-l05`　Harnessの1回の実行に上限を設ける
