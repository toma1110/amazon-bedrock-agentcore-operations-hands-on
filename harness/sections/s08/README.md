# 第8章 総合演習｜AgentCoreの機能を組み合わせて5xxを調査する

## この章で学ぶこと

第4章で接続した読取りツールと第7章で選んだHarnessの版を使い、対象期間と件数を指定して調査します。サンプルアプリのHTTP応答・リクエストIDを実ログと照合し、事実、原因候補、追加調査を分けて報告します。

## 講義とハンズオン

- `s08-l02`　対象と期間を指定し、実ログとエージェントの回答を照合する
