# 第6章 エージェントの実行を観測し、評価する

## この章で学ぶこと

呼び出しのログ、メトリクス、トレースを使い分け、モデル・ツール処理と対応する記録を追います。CloudWatchでGatewayの応答開始までの時間（`Latency`）と接続先APIの実行時間（`TargetExecutionTime`）を同じ条件で比べ、次に調べるログやトレースを選びます。固定ケースの回答も評価します。

## 講義とハンズオン

- `s06-l03`　モデルとツールの処理をトレースで追う
- `s06-l05`　Gatewayの応答が遅いとき、接続先APIの処理時間と比べる
- `s06-l07`　AgentCore Evaluationsで一つの実行を評価する
