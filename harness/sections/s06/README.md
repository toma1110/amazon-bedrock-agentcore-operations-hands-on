# 第6章 エージェントの実行を観測し、評価する

## この章で学ぶこと

CloudWatchでTransaction Searchの設定とログの閲覧権限を確かめて、モデルやツールの処理をたどります。呼び出し制限の記録を調べ、Gatewayの遅延を接続先APIの処理時間と比べます。アラーム設定画面では、監視する指標と条件を選びます。オンデマンド評価にCLIを使う場合は、ブラウザー上のAWS CloudShellで実行します。

## このページで案内する講義

- `s06-l03`　CloudWatchの設定を確認し、モデルとツールの処理をトレースで追う
- `s06-l04`　遅延・失敗・呼び出し制限の記録をCloudWatchで調べる
- `s06-l05`　Gatewayの応答開始までの時間と接続先APIの実行時間を比べる
- `s06-l07`　AgentCore Evaluationsで記録済みの実行を評価する
