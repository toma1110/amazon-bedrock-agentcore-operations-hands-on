# 第3章 AgentCore Runtimeとセッションを管理する

## この章で学ぶこと

東京リージョンで新たに作るRuntimeを使い、実行環境の世代（V2）、エージェントの版、セッションIDを確認します。Memoryを無効にした状態で、同じセッションIDと新しいセッションIDで呼び出し、実行記録を比べます。

- `s03-l06`　【補足】配布済みアプリをRuntimeにデプロイする
