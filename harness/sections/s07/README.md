# 第7章 評価で更新を判断し、版を切り替える

## この章で学ぶこと

基準版と一つの設定を変えた候補版を同じ評価条件で比べます。結果、応答時間、利用量から採用を判断し、名前付きエンドポイントの切り替えと切り戻しを確認します。

## 講義とハンズオン

- `s07-l02`　同じ評価ケースでHarnessの2つの版を比べる
- `s07-l03`　名前付きエンドポイントを切り替え、前の版へ戻す
