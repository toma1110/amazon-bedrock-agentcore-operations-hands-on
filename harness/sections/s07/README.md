# 第7章 Knowledge Basesで手順書を検索し、回答の根拠を確かめる

## この章で学ぶこと

S3に置いた障害対応手順書をナレッジベースに取り込み、同期前後の検索結果を比べます。文書の絞り込み、検索順位、閲覧権限を確かめ、Gatewayを通じてHarnessから共通手順書を検索します。

## このページで案内する講義

- `s07-l01`　S3の障害対応手順書を取り込み、同期で更新を反映する
- `s07-l02`　検索結果と回答の出典を確かめる
- `s07-l03`　閲覧権限の異なる2人で同じ手順書を検索する
- `s07-l04`　Gateway経由でHarnessに手順書を検索させる

閲覧権限の実習では、専用の教材環境で2人の利用者としてサインインし、認証時に確認した利用者情報を検索に渡して結果を比べます。Harnessから使う検索ツールには、総合演習で使う共通手順書だけを収録したナレッジベースを接続します。
