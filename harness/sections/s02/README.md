# 第2章 マネージドHarnessでエージェントを動かす

## この章で学ぶこと

モデルに質問する場合と、Harnessがモデルやツールの呼び出しを進める場合を比べます。Memoryを明示的に無効にし、実行ロールと`allowedTools`を確認します。決めた質問を送り、使われたツールとその結果が回答にどう反映されたかを確かめます。

## このページで案内する講義

- `s02-l03`　モデル・指示・許可するツールを設定してHarnessを作る
- `s02-l04`　Harnessを呼び出し、ツールの結果と回答を確かめる

## 次の章へ

呼び出しに使ったHarnessと結果を控えます。第3章ではRuntime上の実行環境とセッションの違いを確認します。
