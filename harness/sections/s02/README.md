# 第2章 マネージドHarnessでエージェントを動かす

## この章で学ぶこと

モデルへの一回の質問と、指示やツールを組み合わせて処理するHarnessを区別します。設定したHarnessを呼び出し、ツールの実行結果が回答にどう反映されたかを確認します。

## 講義とハンズオン

- `s02-l03`　モデル・指示・ツールを設定してHarnessを作る
- `s02-l04`　Harnessを呼び、ツールの結果と回答を確かめる
